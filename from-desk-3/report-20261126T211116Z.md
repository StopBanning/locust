## Row 2: a browser holding the window hears what the window hears

**The one hook.** `phone_section::mirror_desk(s)` runs as the last line of every window `poll`, at `apps/native/src/main.rs:2755`. That is the WIP's single line in main.rs and the only main.rs change in this lane:
`    phone_section::mirror_desk(s);`

**What the hook does.**
- It does nothing while no browser holds the window (`DeskHost::active()` is None).
- While a browser holds it, it reads what the window heard and compares that with the previous poll. Whatever changed goes through `DeskHost::mirror`, then `flush`.
- A browser that has just taken the window starts from what the window shows at that moment. Cards already waiting reach it through its own `replay: 'approvals'`, as in Electron.

**What I changed from the WIP:**
- **Dropped the invented `run.started` / `run.completed` events.** Electron's NormalizedRuntimeEvent carries `id`, `occurredAt`, `sourceAdapter` and the run's own sequence. `running()` lists conversations, not runs, so an event built from it would not be Electron's.
- **Dropped `away:since-changed`.** The WIP read it from `home.cover_sleeper.away_since`, which is the Home Hopper's pointer clock in milliseconds. Electron's `since` is the ISO time the window lost focus (shared/away.ts `wasAway`). Row 1's notes had mapped it the same wrong way; I corrected DESK-NOTES.md.
- **runId:** the WIP set it to the mission id; it is now `run_<mission>`.
- **Restructured** into a pure `desk_news(was, now)` over a `DeskHeard` reading.
- **Removed `mirror_window_event`.**
