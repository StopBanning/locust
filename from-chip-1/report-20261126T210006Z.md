## Row 2 (25d8f324): the mode chip
**Cause.** A conversation with no teammate has an empty `runs_in`, and `mode_facts::fact("")` falls back to Ask.

**New:** `composer_mode::mode_shown`, which copies App.tsx's mode state. It takes the first of:
1. a mode picked on the box;
2. the mode the conversation's newest turn recorded (`followRouteOf`), if the agent can run it;
3. the teammate's own mode (`selectTeammate`);
4. App.tsx's starting mode, Accept edits.

It then applies Composer.tsx's `effectiveMode`, so it never shows a mode the route can't run.

**Results:**
- (a) the conversation with no teammate that ran in Auto shows **Auto**;
- (b) a teammate with `runs_in` set shows its own mode;
- (c) a new conversation that nothing gave a mode shows **Edit**.

Electron has no unit tests for this state, so the expected values come from App.tsx and Composer.tsx source lines, cited in the tests.
