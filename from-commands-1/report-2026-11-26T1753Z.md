## What each row changed
1. **Reading (eea45866).** New `core/src/own_commands.rs` ports readTree and parseOwnCommand:
   - It reads `<profile>/commands` (the profile is the Electron data folder, `store.electron()`), then `<folder>/.locust/commands`.
   - Nested names work (`team/review`). Each command keeps which folder it came from.
   - It reads the top-of-file description, teammate and mode, using Electron's mode words.
   - A block that is never closed is treated as part of the prompt.
   - It leaves out: names starting with a dot, links, non-.md files, files over 100,000 UTF-16 units, unreadable files, and folders below the eighth level. It reads at most 200 per folder.
   - A missing folder gives no commands and no error.
   - One difference: Rust reads entries in name order, where Node takes whatever order the disk gives.
   - In the window, `src/ui/own_commands_ui.rs` reads the list in a job. It reads again whenever the conversation, its teammate or the open folder changes.
2. **A file becomes a prompt (42133f09).**
   - Ported: `expand_template` ($ARGUMENTS, $1/$2 with the last taking the rest), `split_command_words`, `bang_blocks` and `arguments_of_own_command`.
   - `expand` ports the host's expand step:
     - With no `!` line, the prompt is returned at once.
     - With `!` lines, the terminal policy is checked first and can refuse.
     - A folder's own command asks first, listing its lines, until the folder is allowed in `command-allows.json`.
     - Then each line runs in the folder, and Electron's text "output of \`cmd\` (exit 0):" replaces it.
     - The refusals use Electron's words.
   - Also new: `allow`, `allowed`, `run_line` (runs `<shell> -l -c` in the folder), and `own_command::leave_command_mode` (Escape in the box).
   - "Reaches the next message once" was already carried (`src/ui/command_carry_tests.rs`); I did not change it.
3. **The / menu (e11653ea).**
   - `SlashAction::Own(Source)` and `composer::own_slash_commands` add the person's commands to the menu.
   - Order is Composer.tsx's: Locust's own, then the person's, then the agent's. The person's stay offered while a turn runs; the agent's do not.
   - Group labels are "Your commands" or "This folder". The detail is the file's description, or else "A command of yours." / "A command in this folder."
   - A name Locust already uses (like plan) stays Locust's.
   - Typing `/name the rest` offers that command alone, and Enter chooses it.
   - Choosing a command expands it in a job (`own_commands_ui::choose`), then applies it as applyOwnCommand does:
     - It takes the file's mode if the policy allows it. For Auto, it first turns on the Auto setting.
     - It takes the file's teammate if one has that name.
     - The prompt goes into the box and attachments are cleared. Nothing is sent.
   - A refusal changes nothing, as in Electron.
   - The CommandAsk card is drawn under the box by `terminal_panel::commands`, with role dialog and Electron's words. While it shows:
     - The menu is closed.
     - Enter neither sends nor chooses, and `submit_composer` does nothing.
     - Escape (or Not now) closes the card. Allow allows the folder, expands again and fills the box.
4. **Open folder (2450388f).**
   - `open_folder` / `open_folder_here` / `directory` port OWN_COMMAND_OPEN.
   - The folder is created if missing, then opened with `/usr/bin/open` (Mac) or `xdg-open` (Linux).
   - With no folder open: "Choose a folder first. There is nowhere to open." (Electron's exact words), and nothing opens.
   - The opener's error is passed back as the answer.
   - If the folder cannot be created: "That folder could not be opened. Your commands are where they were."
