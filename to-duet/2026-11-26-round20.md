# Round 20 (26 Nov 2026, ~21:50 EST): Hover 1, the hand and the light on everything you can press

Rounds 17-19 are in, thank you. This round is one track, and it is the change a person notices first.

## Why
The owner drove the Rust app beside Electron today. Two things he said: hover states don't show on what can be pressed,
and the pointer never turns into a hand. A cited map of Electron's rules is in `docs/HOVER-MAP-electron-2026-11-26.md`
on `exec/native-engine` (if it is not on the branch yet, the findings you need are below). What it found:
- Rune has the whole OS cursor pipeline (`vendor/rune/crates/rune/src/cursor/os.rs:48-65,168-181`), but
  `Runtime::cursor` (`vendor/rune/crates/rune/src/runtime/input/pointer.rs` ~364-390) sets `Cursor::Pointer` only for
  inline `Link` spans. Across `apps/native/src`, `Cursor::Pointer` is never used, so no button, row, tab, chip, menu
  item or card shows a hand.
- Of 483 `.on_press` handlers in `apps/native/src`, only 62 have a `.hover(...)`.
- Rune has no `hover_border` on `El`, which blocks Electron's ~35 border-lift hovers on cards, pills and buttons.
  `El::group_color` and `El::hover_motion_within` exist and are unused.

Rows, in order:
1. **The hand on everything pressable.** In Rune, an element with an `on_press` (or `on_press_at`) handler that is not
   disabled/inert shows `Cursor::Pointer` while the pointer is over it, unless it sets its own `.cursor(...)` (which
   wins: text fields keep the I-beam, resize handles keep theirs). Disabled shows the default arrow (Electron's
   `cursor: default` on `:disabled`; find the rule). Tests in Rune's own tests (`vendor/rune/crates/rune/tests/`): a
   pressable element gives Pointer, a disabled one gives Default, an explicit cursor wins, a plain element gives
   Default, a Link span still gives Pointer.
2. **`hover_border(color)` on `El`** (and a `group_border` if `group_color`'s pattern makes it cheap): the border colour
   changes while hovered, with the same transition rule `.hover` uses. Rune tests.
3. **Use them where nobody else is working:** `apps/native/src/look/controls.rs` (the switch at ~127-150 has no hover:
   Electron's switch hover, find it in shell.css), and Rune Kit's own buttons if they lack hover/border-lift (match
   Electron's `.lc-btn` family). Window tests that hover a switch and a button and read the colour change.
