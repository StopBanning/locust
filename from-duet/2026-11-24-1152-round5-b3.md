## Engine behaviour changes
- Codex can be steered while a turn runs (turn/steer).
- Codex stray lines no longer end the run. A blank line is skipped, and a non-JSON line becomes a non-terminal diagnostic.
- An answer from Codex to no request becomes a diagnostic instead of being dropped.
- Codex timeout wording: "The app server did not answer <method> in time." (was "Codex timed out answering …").
- Codex sends no empty `config` on thread/start, resume or fork. scripts/fixtures/m1-app-server.py now accepts a missing config.
- outputLimitExceeded is set for Codex when its queue overflows or a line is too long.
- Codex tool name and status are capped at 512 characters, with NUL removed.
- Muse says when Locust stopped the run (a line over 8 MiB or a full record queue), instead of saying no record showed the run finished.
