## Engine changes (batch 6)
- **Codex file changes (row 343, approval-channel):** a Codex fileChange tool row used to name its files as absolute paths and carry no patch. The new `approval::with_file_changes` runs in codex.rs before `with_declines`, using a new `folder` field set when the turn starts. The row now gets its paths relative to the run's folder, and its patch. A declined or failed change keeps its paths but gets no patch.
- **Forget (row 390, forget-hits-one-memory):** a forget used to hit only an exact quote. The new `people::forget_match` follows Electron's forgetMatch: exact match first; otherwise the quote must be inside a memory, or the memory inside the quote, counting only words over two letters. If several memories match, it's ambiguous and nothing is forgotten; `forget_target` names the candidates. Two native behaviours are kept: an empty store still answers NothingRemembered, and two memories with identical text still count as ambiguous.
- **Global memory from another folder (row 1169, memory):** `briefed_rows` marks it with that folder's name, so the brief line reads "(everywhere, by Wren in ledger)", as Electron's does.
