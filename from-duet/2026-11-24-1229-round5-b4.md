## Engine behaviour changes
- **Ledger writer (rows 1215, 1216):** `LedgerWriter::append` used to write events its own reader would stop at. It now refuses them through a new `ledger_write::readable_event`, with the error "Mission event is not readable by the ledger reader", and leaves the file untouched. It refuses two kinds: a tool event whose `parentItemId` is empty, blank or not text, and a `message.delta` whose operation is neither append nor replace. A merely long message is still kept, shortened.
- **Old check results (row 1214):** `mission_export::recover_mission_from_path` reads a check result in a file written before version 17 as damage ("invalid-record", no check), as Electron's reader does. The bound case is tested on the record the host actually writes (`edit_check_record_json`).
- **Memory order in the brief (row 1144):** a turn's brief used to list memories in the store's order, so a memory rewritten today sorted by the date it was first kept. `briefed_rows` now orders by last write, through a new `memory_file::by_last_written` (Electron's byLastWritten; equal dates keep the store's order). A rewrite from today leads the brief and says "today".
